Инструкция по созданию автотестов на Python.

Важные правила:
1. Работаем с  автотестами всегда в venv, туда и устанавливаем все модули. (Для деактивации окружения, если оно активно используем deactivate)
2. Как только скачал проект, и настроил venv, если есть файлик requrements, то все модули что есть внутри этого файла, их необходимо установить. 
    Быстро установить все из файла (pip install -r requrinments.txt)
3. Всегда в файл .gitignore добавляем скрытые, личные каталоги, с локальными настройками: '.idea', 'venv', _pycache_ , .pytest_cache
4. Для установки модуля в Python используем команду: pip <name_module> install
5. Посмотреть какие модули активны в этом окружении используем команду pip freeze
6. С помощью команды 'pytest' в терминале и запускаются тесты питона, но выполнятся они только в том случае, если будут соблюдены условия заапуска
	* Первое условие название файла должно содержать test, не содержать пробелов и кириллицы
	* Второе условие название функции должно содержать test
7. Для просмотра тестов и их статусов, после выполнения используем команду: 'pytest -v'
8. Фикстуры используем для подготовки тестового окружения, управления данными и последующей очистки ресурсов перед и после выполнения тестов. 
    * Всегда храним фикстуры в файле conftest.
